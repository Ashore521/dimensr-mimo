# 通用结构匹配的共享提案：下一阶段

## Material Passport

全池物理选优之外仍需实际发现紧凑的联合系统。已冻结compound_search_20261027/damped_n0_s701_compound池有7个训练/验证逐输出误差≤1e-4的候选（索引7、8、86、88、90、142、147），但没有同时通过原结构/相对门槛的候选；这只是既有开发池诊断，不是新增性能结果。原候选、原始近零项和精度/结构门槛不改。

现有GP share从其他输出中按单位匹配随机选择子图，bind只绑定参数身份。可评估一个通用、受限的提案策略：先识别跨输出具有相同算子/变量/单位结构的子图，允许其参数身份和数值不同，提出整子图共享；随后必须经完整系统联合常数拟合、域/预算/逐输出误差检查。结构匹配不代表函数等价，不能在原保存模型上直接合并或删除节点。

不得识别任务名称、已知频率/包络公式或真值参数，不得以近零系数直接改判旧模型。需保持现有评价/初始化/墙钟预算，记录实际提案、变化和有效评价，并保留原随机共享路径作为对照。候选规模、匹配排序、是否保留参数别名模式、单次提案上限及消融在实现前明确。

下一阶段先构造量纲、绑定参数、跨输出共享及不可行候选测试，再冻结包含旧成功任务、阻尼/有理族、噪声及系数/单位变体的有界对照。全部新模型封存后评分；与物理选择器的改变分开，不能把重选收益归于搜索或把机制通过等同于完整目标完成。

## 2026-10-28 实现前固定的提案规则

- 新选项 `sharing_strategy='matched'`；默认 `random` 保持原路径。仅在原 share 事件中以 1/2 概率尝试匹配，另一半保留随机 share；其余共享/解绑/变异/交叉和总体评价预算不变。直接 `matched_share` 运算供构造测试及归因使用。
- 比较有算子且含参数的跨输出子图。按根先序遍历编码算子、变量编号、精确量纲，参数按首次出现局部重命名，保留子图内参数重复绑定模式；忽略参数实际值及全局编号。算子顺序保持，不进行交换、化简或近零项删除。匹配本身没有等价性承诺。
- 每输出最多枚举 256 个路径，图节点按拓扑编号遍历；匹配对按被替换子图展开节点数降序，然后输出编号、路径、供体节点编号升序。最多构建前 64 对，去重后保留最多 16 个严格减少共享图规模的完整系统提案；以现有随机数源等概率选择一个。无合格项时消耗本次尝试并明确记录为无变化，不额外评价。
- 供体来自另一个输出的可达节点。替换仅针对选定路径；其余引用与参数保持原样，Builder 仅裁去不可达节点、拓扑重排与参数重编号。随后沿用完整联合拟合、原数值域筛查、原结构预算和全部输出约束。
- `operations/changed/novel/successful` 原运行统计分别记录 `matched_share` 的尝试、实际图变化、新评价和有效候选，不能凭配置开关声称生效。
- 构造测试须覆盖不同系数的同结构并非等价、重复参数别名、不同变量/量纲不匹配、原参数和模型不变、共享图严格缩小、真实联合重拟合、不可行域与大小预算拒绝、旧 random 路径兼容。
- 实验独立目录将在测试通过后建立；先冻结协议、代码、矩阵、消融与资源再运行。旧成功、阻尼/有理、噪声和单位变体分层报告，物理重选 API 不参与本轮方法差异。
