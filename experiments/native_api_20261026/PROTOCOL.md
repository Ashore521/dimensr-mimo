# 原生接口接入与物理坐标交付

目的：证明可选原生配置保持已验证研究候选的搜索行为，并验证一次真实拟合的物理坐标交付。生产默认不变。版本升为1.1.0，增加向后兼容的显式配置与接口。

## 冻结矩阵

- products/legacy、dimensional_frequency/legacy：与改动前有效基线逐字段核对。
- dimensional_frequency/normalized、partial/normalized、high_dimensional/normalized：与corrected基线比较搜索指纹、完整候选池、操作计数、去除计时的阶段事件；最终结果与旧冻结池的归档precision选择器比较。
- affine_lengths/physical：两个长度输入域[8,12]和[90,110]，输出2*x0+3*x1+5、x0-x1+2均为长度。先划分96训练/48验证，再仅用训练数组计算坐标。原物理数组复算、JSON独立解释、保存重载逐元素一致。

所有神经、GP、NSGA-II、局部Rademacher、量纲、共享、退化约束均启用，必须以运行事件和计数证明执行。五个等价单元保留原1200评价、180初始化名额、原常数拟合预算。物理示例配置冻结于FREEZE.json，既不针对结果调预算，也不在失败后替换任务。

单工作进程、数值库单线程，fit52秒、单元外部60秒、总矩阵400秒。超时/失败保留在六单元分母，不覆盖重跑。外部监督记录整个工作进程树RSS。源码副本、输入生成器及验证器哈希先于运行冻结；模型保存后再做独立核验。不访问测试数据。

搜索精度门槛每输出NRMSE≤1e-4，图size≤24，独立参数≤6，展开节点≤30，深度≤6。物理示例独立冻结门槛每输出NRMSE≤1e-4，图size≤48，独立参数≤14，展开节点≤64，深度≤10；这些结构额度包含固定坐标代换开销。未满足即明确not_met，不以完成运行代替验收。

三个最初normalized捕获遗漏调度的事故保留于baseline/INCIDENT.md；它们不能用于等价证明。baseline_corrected三个完整参考必须与第七轮种子601对应normalized搜索、池和变异计数吻合。

本轮是软件接入回归，不是新公式族、含噪声、独立盲评或真实物理数据研究。通用物理图选模仍只检查搜索坐标中选出的模型，不承诺全池物理复杂度最优。
