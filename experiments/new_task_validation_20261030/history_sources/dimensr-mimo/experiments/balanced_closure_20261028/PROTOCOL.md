# 两轮均衡闭包：冻结开发对照

本轮仅按PLAN.md将每轮新评价上限设为24；其余按前轮固定规则执行，可选sharing_strategy='closure'，默认仍random。依据search_lineage_20261028的训练侧诊断，只改共享提案的执行位置、基础池保留和基础选择参照；不解决或预称解决剩余有理式精度问题。本轮为已检查历史任务/开发变体回归，不是盲评。

## 算法和消融

random为完整原联合搜索；closure先执行同一random神经/GP/NSGA-II/polish，再在验证评分前增加最多2轮、每轮16父、每轮最多24次新评价且总计最多48次的匹配闭包。匹配器沿用1.6.0的256路径/节点、64匹配对、16提案边界。基础池与全评价缓存摘要分别保留；不refine缓存图，不消费基础RNG，不删除近零项或识别任务名。

父代按训练平均误差、复杂度、图摘要排序。新图按训练warm预测相对父代的最大逐输出标准化变化、共享图大小、父训练误差、子图摘要、父图摘要排序。同图保留最先排序的提案。正常联合拟合/量纲/数值域/Rademacher后，子代全部输出训练误差须≤父代×1.1+1e-8。每轮未用满的24次不转移，48次总限计入原1200评价与52秒fit，剩余不足即停；无额外重启。

闭包结束后才计算验证误差。基础候选验证无效则显式失败（原precision路径在该情形也不能选择）；新增候选的非有限预测、越界或溢出误差只作拒绝并保留图ID/原因，绝不再搜索。保留验证前完整训练pool摘要，并对供原selector使用的有效子集另存摘要。训练保护通过数与验证后保留数分别报告。

从基础池按原precision规则重算基础选择。扩展池必须同时满足所有旧绝对精度/结构、训练初始化约束和原基础加权锚点验证保护，并且逐输出训练/验证误差均≤基础precision选择×1.1+1e-8；再按原结构优先级选模型，没有可行项则返回基础precision选择。此约束不保证干净测试保护。保存重载重算基础前缀摘要、选择、边界及结果；运行计数与父子证据另由本轮核验。
