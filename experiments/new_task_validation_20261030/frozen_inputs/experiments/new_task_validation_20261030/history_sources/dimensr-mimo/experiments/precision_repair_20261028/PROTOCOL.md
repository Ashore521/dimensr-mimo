# 保留基础搜索的训练精度补充：冻结开发回归

本轮依PLAN.md和PRE_RUN_REVIEW.md，原17任务/种子对共34系统比较base/repair。两臂均使用compound初始化、原完整神经/GP/NSGA-II/polish、closure两轮24+24及precision选择；唯一配置差异为precision_repair=false/true。种子奇偶反转两臂顺序。训练/验证/测试96/48/192，任务均已参与开发，结果不称盲验证。

repair在原基础搜索结束、验证评分和matching closure之前检查完整基础池：只要任一系统的每输出训练NRMSE均不超过该任务既定acceptance.nrmse，就完全跳过补充；触发不使用结构、验证或测试指标，不按任务名分支。触发时使用通用implicit structured_seeds，每输出最多min(12,population_size//输出数)个。按原索引组合系统，该输出在索引k没有种子时复制固定训练父根，不循环使用短列表。至少一个根必须来自该输出的implicit_retained_indices，才允许评价。固定父取基础池平均训练误差、复杂度、图摘要的字典序最优系统。新系统使用原Evaluator完整联合常数拟合、单位/数值域和Rademacher路径；每输出训练误差不超过父×1.1+1e-8才留存。不得refine基础状态或缓存图，包括缓存失败图。

最多12次缓存外repair新评价，其后原matching closure每轮最多16父、24次新评价，合计最多48次。两阶段共同消耗原1200系统评价、52秒fit；单系统外进程60秒，数值单线程串行。总2880秒含600秒评分/核验预留，外层每0.2秒监督进程树。新增隐式生成响应同一deadline；检查为合作式，不能抢占正在执行的单次NumPy/BLAS调用。失败、超时和预算未启动全部保留，不补跑、不缩分母。

原基础前缀在repair前冻结，其count/hash及全部有效Evaluator缓存摘要不得被补充改写。完整训练池严格拼接为基础+repair保护留存+matching保护留存；两类事件、有效数、保护数和新评价数分开保存。总评价=基础评价+repair新评价+matching新评价。验证可拒绝新增候选，不能重启搜索；验证留存扩展和全部拒绝记录覆盖两类候选。最终precision基础训练/验证参照仅来自原基础前缀。

冻结源码、脚本、全部测试与验证日志、PLAN/本协议/PRE_RUN_REVIEW/TRAINING_GATE_AUDIT、依赖版本、预算和训练验证摘要，以及复现所需历史依赖和旧模型兼容测试输入。每单元封存后才进入下一单元，全部模型封存后才统一评分；保留freeze→单元→全模型→评分→验证hash与时间链。独立原始JSON解释器复算每个候选训练/验证及所选模型测试误差，核对单位、结构、域审计、真实重载和机制。两臂每系统仍须有效神经候选、策略变化、GP新评价、至少两个NSGA-II step分别有新评价和Rademacher。matching两臂各自批内新评价/有效/保护/验证留存均须大于0；repair批内须实际触发、隐式线性子问题、获胜隐式根、含隐式根的完整系统缓存外新评价、有效拟合和训练保护留存均大于0，另行报告验证留存数。允许单元如实记0，开关本身不作为机制证据。

新增配对门槛：17对原基础前缀count/hash/评价数与有效cache摘要均相同；未触发repair的单元，其整个验证候选池、最终有效cache摘要及所选系统/常数/指标均与base相同。墙钟扰动导致不一致时如实判失败，不以相同上限替代相同轨迹证据。验证器分别回放repair与matching，再核完整池和验证子集，不调用旧closure verifier的基础+闭包总量等式。

原完整接受阈值不变：无噪声每输出train/validation/test NRMSE≤1e-4；1%噪声观测≤.03、干净测试≤.02；标度为训练观测标准差。共享图≤24、独立参数≤6、总展开节点≤30、最大深度≤6。采用要求全部满足：34/34技术核验；34/34干净输出≤base×1.1+1e-8；保留全部base已接受案例，总接受不降、宏平均干净误差不升；repair的damped_n0/701图≤20且各train/validation/clean≤1e-12；rational_n0/702完整接受且各train/validation/clean≤1e-4；以及上述配对身份门槛。任何单元失败保留34系统/34输出分母，均值不能抵销退化。
