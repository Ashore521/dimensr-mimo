# DimenSR 历史复测 v2：预算控制修正

用户已授权依次修改算法并重新拟合。本轮实现与拟合均只写入本目录；v1 和两个原始仓库保持原样。

## 固定网格与数据

沿用 v1 的 76 个多输出系统、196 个逐输出独立 DimenSR 模型、17 个训练/验证划分与八项真实任务。legacy 为前三项各 2 个种子；CV 为前三项各 3 外折 × 5 种子；new 为 Gas/SML 各 5 种子；external 为 Tetouan/Water/Video 各 5 种子。全部种子、行号、训练样本上限、标准化和目标尺度均沿用历史冻结记录。external 输入已标准化，禁止二次标准化。

系统预算为 legacy/CV/new 各 20 CPU 秒、external 各 25 CPU 秒，总额 1595 CPU 秒；每输出分配 B/m，不转移未使用额度。维持 max_nodes=13、种子及其余原生默认设置。目标仍为原数值单位，符号量纲声明为无量纲。本轮不改单位检查、数值合法性检查、复杂度或验证选择准则。

## 修改与预算口径

1. 原生进程 CPU 截止时间贯穿结构生成、系数拟合和搜索；单个线性代数、Torch 或合法性核验操作采用协作检查，允许完成当前原子操作，必须报告实际超时。
2. 初始化在设置完成后最多使用剩余额度的 20%，且不越过第一阶段截止点；首个合法常数回退允许完成。结构候选逐个生成并立即正式评估，取代先完成全部枚举再返回。该顺序会改变限时搜索轨迹；不限时路径保留原全局排序。
3. 第一阶段截至总额 75%；剩余第一阶段时间按原 6 个 epoch 分配，epoch 内神经采样占 50%、GP 截至 85%、余量用于策略更新。NSGA-II 使用第一阶段结束后剩余时间的 90%，末尾余量用于原有精修。设置也计入预算；最终验证选择、导出、重载和域审计另列。
4. 同一系统输出间只缓存完整的输入特征库，键含 X 内容及语法约束；不共享 y、系数、目标相关排名或最终模型。训练仍为逐输出独立。
5. 监测实际 Python worker PID 及 OS peak working set，检查其与本次 Windows venv 启动器的父子关系。最多 2 个单线程 worker，监测上限 2 GiB/worker，墙钟上限沿用 legacy 240、CV/new 120、external 300 秒。超限终止实际 worker 并等待系统确认。采样间隔 0.25 秒，属于监测与终止机制，不是操作系统硬内存配额。

## 冻结、评分与比较

训练只使用训练行；原生选择器只用验证集。所有 76 个系统达到终态后全局封存模型与日志，然后统一打开历史测试数据评分。保留所有失败、超时与候选不足，不根据测试误差重选种子、重跑或调整算法。

对照冻结 v1、原有联合 MIMO、可匹配的独立符号搜索；均值/Ridge/Extra Trees 仅作历史背景。前三项旧留出联合 MIMO 为固定三代、没有匹配独立结果，也不是等 CPU 预算。45 个 CV 系统另表，不混入八项旧留出平均。旧测试已检查过，结论只属于回归复测，不是新盲测或总体统计优越性。

## 验证与交付

正式运行前通过中断/缓存/限时活跃性/常数回退/模型重载测试、实际 Windows 子进程监测与终止测试，以及原有相关功能测试。正式结果报告每模型神经采样、GP 变化、NSGA-II 新评估、策略实际更新、候选覆盖、常数选择、预算与内存；不能以有返回模型代替搜索充分性。
