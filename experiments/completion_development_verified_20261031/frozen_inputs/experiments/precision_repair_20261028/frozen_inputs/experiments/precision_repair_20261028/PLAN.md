# 保留基础搜索的训练精度补充：实施前方案

## 证据和未决原因

implicit_rational_20261028通过34/34技术、接受10→15并解决指定有理精度，但逐输出保护30/34，采用失败。替换初值改变后续整条搜索轨迹；四项退化尚未定位到某个算子/拟合/选择阶段。全部134冻结输入及运行证据已按原字节保留。不能据测试分数逐案例切换模型。

TRAINING_GATE_AUDIT.json只读取对照compound臂的原基础池训练误差和事前acceptance.nrmse，未使用验证/测试指标、没有搜索/重拟合。17池中只有damped_n0/702和rational_n0/702没有任何全输出训练精度达标状态，其余15池均有。此事实支持一个通用保守触发规则，而不证明补充后会成功。

## 固定算法

新增默认false的precision_repair布尔选项，要求initialization='compound'、sharing_strategy='closure'和原precision接受配置。先完整执行原compound神经/GP/NSGA-II/polish，保留全部基础池和有效评价缓存摘要；此阶段代码及随机轨迹保持原逻辑。

在验证评分之前、原匹配闭包之前检查基础池：若存在任一候选满足每输出训练误差≤配置acceptance.nrmse，直接跳过精度补充，继续原24+24匹配闭包。检查不含结构条件、验证误差、任务名或测试标签。训练已经达标而仅结构不够的系统仍由原匹配闭包处理。

仅当该基础池没有任何全输出训练达标候选时，调用已审查的通用implicit structured_seeds，每输出最多12（且不超过population_size//输出数）；按原索引组合完整MIMO系统，缺少某输出候选时从训练最优基础父系统复制该根。至少一个根须来自实际获胜的隐式初值，否则不评价。最多12次缓存外完整系统新评价，不refine任何缓存图或基础状态；遇到全局评价/墙钟截止即停。正常联合拟合/单位/域/Rademacher全部保留。

训练父参照固定为基础池按平均训练误差、复杂度、图摘要选出的最优系统。补充子图每输出训练误差须≤父×1.1+1e-8才进入扩展池，完整父/图/warm/子/计数保存。此处不要求图一定更小；最终原精度/结构与逐输出保护仍必须通过。没有有效补充也完整保留原基础池。

随后原两轮匹配闭包在基础+已保护补充状态上执行，每轮16父、24新评价，总48；精度补充最多12与匹配最多48均计入原1200评价和52秒fit，既定总上限不增加。冻结前记录基础前缀摘要不变，完整训练池为基础+补充保留+闭包保留，分开记两类事件。验证过滤后的新增有效子集与全部拒绝均可回放；最终基础precision训练/验证参照仍只来自原基础池。

## 实施与验收

1. 最小新增repair.py与配置/路由，复用现有implicit原函数、Builder、Evaluator和闭包；保存重载不接受篡改基础前缀。构造测试覆盖门槛skip、实际新图联合fit、父保护、12/全局/墙钟限制、基础不变及重载。历史及失败原样保留。
2. 新上下文独立核心审查和harness审查，适当全套/定向测试后再冻结执行。
3. 正式34系统为原17对base/repair，两臂均compound+closure24+24，唯一变量为precision_repair。原52秒fit、60秒单元、1200评价、2880秒总含600秒核验预留、数值单线程、外部监督不变；失败不补跑。17对分别核验原基础前缀和有效cache摘要；未触发单元检查整个池和最终选择是否与base相同，墙钟差异若破坏一致必须如实报告。
4. 全模型封存后统一测试评分，独立核原图/全部候选训练验证、所选测试、单位/域、重载、完整神经/GP/每至少2个NSGA有新评价step/Rademacher机制。补充按批内合计须有触发、隐式线性子问题、缓存外新评价、有效拟合和保护留存，不能以开关作为证据。闭包各臂仍实际执行。
5. 原采用门槛保持：34/34技术与干净逐输出保护，所有base已接受案例保留、接受数不降、宏平均干净误差不升；damped_n0/701图≤20且各train/validation/clean≤1e-12；rational_n0/702完整接受且各train/validation/clean≤1e-4。新增要求基础前缀与有效cache配对一致、未触发单元完整模型选择一致。失败不降门槛，不按本轮测试分数返工候选。

这是针对训练精度缺口的保守补充，并不试图保留前轮15/17中的全部额外结构收益；它能否同时保护输出与修复有理精度仍待正式证据。即使开发批通过，仍须独立新任务/种子验证，默认和1.7.0发布尚不自动获准。
