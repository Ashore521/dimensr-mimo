# 安装、复现与证据检查

默认安装见 README。`docs/environment.txt` 记录本轮独立 CPU 环境的精确版本；原始 DimenSR 目录和环境不参与新版运行。若需要重现本轮环境，先按文件中 PyTorch 版本从 CPU 索引安装，再安装其余版本及本项目。不同硬件、BLAS 或 PyTorch 版本可改变浮点搜索轨迹。

## 算法与消融

完整机制包括输出上下文条件 GRU 的 token 和量纲产生式采样、系统训练奖励的风险寻优更新、优秀系统的独立模仿损失、神经/GP 交替、训练候选筛选、多代父子代合并 NSGA-II、拥挤距离和尺寸密度选择。`_single` 保存原版完整单输出流程，仅供数值基础和独立对照使用。

输出参照由合法初始化候选逐输出最佳根组装，参数复制为各输出独立起点，训练误差阈值随后冻结。参考式的验证误差只在搜索结束后计算。NSGA-II 使用约束优先支配，再按两个目标排序；违反量不构成第三优化目标。最终验证从已冻结的候选池中选择，不重新进行结构或常数搜索。

常数优化在全部输出上最小化归一化平方残差；结构搜索优化各输出 NRMSE 的平均值。两者都是联合目标，形式并不相同。绑定参数只拥有一个拟合坐标。结构引用产生式直接引用此前输出中的节点；参数叶也可被引用。GP 还允许任意同量纲引用、局部私有修改、共享节点共同修改、绑定与解绑。节点大小上限按每个输出的原始展开式检查，复杂度按实际共享图计算。

神经可引用的槽数有限（默认 12）；GP 可产生超出该引用词表表达能力的系统。不能精确回放的精英会跳过模仿并记录 `imitation_unrepresentable`，不会把错误的似然用于训练。局部 Jacobian、区间数值筛查和有限量纲目录的限制见架构文档。

## 首轮复现

`experiments/first_round/PROTOCOL.md` 为预注册设计，`FREEZE.json` 固定源码、版本、方法、任务和种子。实验按单元落盘：`job/config/events/result/resources/model*.json`。无原始数组；输入和输出由固定生成器重建。

已有冻结结果目录禁止覆盖。复现时将整个新版仓库复制到独立实验位置，保留已发布结果；使用新的实验目录并记录新资源预算与运行标识。`study.py` 的 `calibrate → freeze → train → evaluate` 分离训练和评分。预算计时从首次校准预检开始；已有 BUDGET.json 不自动重置。正式模型全部写完后才产生 `ALL_MODELS_FROZEN.json`，然后评分脚本才生成测试标签。

`train` 可跳过已完成且有资源记录的单元。若只有 job.json 而无 resources.json，表示中断且需先检查残留进程与已有文件，不自动覆盖重跑。研究代码冻结后发现问题，应保存事件记录并另立版本，不能悄悄改已冻结算法。

## 阅读结果

第二轮的协议、唯一配置改动与核验脚本位于 `experiments/second_round_20261026/`。正式顺序为 `study.py freeze → train → finish`；`finish` 在同一个总截止时间内执行评分和独立核验。训练只接受训练/验证数据；每单元的 `CELL_FROZEN.json` 保护已完成检查点，全部单元统一冻结后才放行测试评分。完成率的分母固定为 60，原版/改动版的搜索指纹与候选池还要逐对一致。

已发布目录包含不可覆盖的结果。复现应另建独立仓库副本，保留源码、首轮只读证据、第二轮脚本/协议/配置/诊断，以相同路径布局准备尚未运行的第二轮目录；不要复制其中的预算、正式运行目录、冻结清单和评分报告作为新运行输入。`freeze` 会建立新时钟并固定当前文件与环境，不能重置已有预算。原结果中的时间和峰值资源仅适用于原运行机器。

`events.jsonl` 为逐阶段证据。神经参数变化范数、有效神经候选、新 GP 评价、各代 NSGA-II 新评价、共享算子产生的新结构及成功拟合数分别记录。独立 DimenSR 的原回调合并神经/GP，运行时计时包装另记录 `evaluation_gp_new` 等，不修改原版源码。

总体墙钟包括子进程启动和导入。系统上限相同并不意味着实际用时相同，也不意味着不同方法具有相同候选数或拟合次数。进程树资源每 0.2 秒采样；RSS 峰值可能漏掉更短尖峰，末次采样 CPU 可能略低估。拟合与评价耗时嵌套在各搜索阶段中，不能全部相加。

保存加载核验以保存前原模型对训练/验证输入的预测 SHA256 以及域审计结果为依据；测试预测只在统一冻结后执行。报告须同时给出工程完成率、完整机制率、逐输出约束状态与性能结果。

## 第四轮与公开任务

`experiments/shared_discovery_20261026`保存补齐通用三角种子的单项对照，两组均固定guarded选择器；`experiments/public_transfer_20261026`保存随后固定的两个公开任务。都按`freeze → train → finish`执行，结果不可覆盖。第四轮有逐提议/评价轨迹；第五轮保存数据来源、拆分和训练归一化清单，以及原始公开文件到缓存的重建检查。

复现公开任务时，在独立副本的新实验位置保留本轮数据脚本、协议及算法选择依据，先从DATA_MANIFEST.json中的官方URL下载两个归档到`outputs/public_transfer_20261026/raw/uci242.zip`和`uci275.zip`，核对归档SHA256。执行`data.py`会建立训练/验证和封存测试缓存；不能同时保留已有DATA_MANIFEST.json或覆盖既有缓存。原始数组不随仓库或软件包分发。

公开任务的算法、资源及数据清单在FREEZE.json中绑定；全部模型和失败标记封存后才能读取测试缓存。复现运行的新预算、模型、哈希和耗时必须与已发布证据分开保存。报告同时保留训练域和测试扩展范围的数值筛查，不通过时不得删行后重新评分。
