# 固定初始化预算与量纲开发层

36个完整系统在769.77秒内完成并通过原始图重载、单位、候选误差、选模、测试复算、覆盖计数及运行机制核验。生产默认不变。

|方法|精度和结构同时达标|平均测试NRMSE|
|---|---:|---:|
|追加词汇的原前缀分配|4/12|0.10978716|
|同词汇的平衡分配|6/12|0.01461632|
|逐输出独立DimenSR|6/12|0.01807489|

平衡分配相对原前缀的平均误差降低86.7%，24/24个输出满足原前缀误差×1.1+1e-8的保护界。11输入任务两个种子均恢复目标公式，实际每输出22个sin和22个cos种子获得新评价，覆盖全部11输入。它解决了高维初始化截断，但不意味着完整目标已经达成。

固定门槛为每输出NRMSE≤1e-4、共享图size≤24、独立参数≤6、展开总节点≤30和最大深度≤6。动量/动能、不同私有尺度、高维三角三类任务达标；不同输出单位的三角、部分共享和边界组合三类均未达标。全部任务为已知的无噪声开发任务，不能称盲评或实际工程可用性证明。

六个失败系统的训练/验证候选池中均没有满足固定门槛的公式，当前证据支持先修复生成/拟合缺口。轨迹可直接看到不同量纲输出的种子类别错位：例如合法sin种子与另一输出在负输入域上的sqrt种子配对后，完整系统被拒绝。结构种子还缺少对带量纲变量与组合项的通用无量纲化，限制了合法sin/log等复合表达式的生成。后者属于源码诊断，需要后续固定实验确认影响，不能直接归因全部误差。

下一轮将分别检验跨输出类别对齐和结构种子的单位适配，固定最终选择器、评估上限及常数预算，保留二者分开的对照。绝对精度优先选模仍是交付目标的一部分，但不能补救候选池中不存在的好公式。
