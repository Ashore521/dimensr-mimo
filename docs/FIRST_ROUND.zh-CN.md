# 首轮结果：工程机制通过，性能优势尚未建立

完整实验表见 [REPORT.zh-CN.md](../experiments/first_round/REPORT.zh-CN.md)，逐输出误差、R² 和公式见 [metrics_per_output.csv](../experiments/first_round/metrics_per_output.csv)，逐单元运行证据及独立重算见 [VERIFICATION.json](../experiments/first_round/VERIFICATION.json)。

七类合成任务×两个种子×五种方法，共 70 个系统，无失败、无超时。预检、四个短校准系统、正式训练和统一评分共 1765.94 秒（29.43 分钟）。本轮没有按测试结果重训或修改算法。

| 方法 | 平均测试 NRMSE | 实际总墙钟秒 |
|---|---:|---:|
| 完整联合 MIMO | 0.0000717378 | 300.8 |
| 完整逐输出独立 DimenSR | 0.00000420779 | 302.5 |
| 无神经策略 | 0.0000666060 | 252.1 |
| 无 GP 演化 | 0.0000666060 | 268.0 |
| 无共享 | 0.000125239 | 313.7 |

统一上限是每系统 60 秒，独立方法每输出 30 秒。实际用时接近的完整两方法中，联合方法仍没有更低的平均误差。14 个配对里，按 1e-8 绝对差划分，11 个近似持平，3 个联合方法较差，没有明显更好的配对。逐输出差异均未超过“独立误差×1.10+0.02”的描述性退化阈值；这不等于逐输出完全不退化。该描述性阈值与算法内部初始化参照有不同含义。

多数简单任务已接近浮点精度。误差主要集中于共享非线性参数任务和一个尺度差异种子。无神经/无 GP 的聚合误差与完整方法相近且略低，当前小规模结果没有证明神经学习或进化阶段提高了最终精度。初始化较强、问题较简单且种子仅两个，不能把机制“确实执行”解释成机制“已产生性能收益”。

## 共享与神经/进化的实际证据

14 个完整联合系统及 14 个完整独立对照系统都通过对应机制核验；独立对照两个输出分别接受检查。所有预定消融也通过其相应开关/执行路径检查。

完整联合方法中，9/14 个最终模型使用了共享节点或参数。共享算子产生并成功拟合了 377 个引用后代、453 个绑定后代、392 个共同变异后代、29 个解除结构共享后代和 18 个解绑参数后代。它们参与实际搜索和联合拟合，不是最终显示阶段去重。

固定结构单元测试能联合恢复 `sin(a*x0)` 与 `cos(a*x1)` 的共同参数 a=1.7；绑定/解绑也会改变可拟合函数族与残差。但端到端 `shared_parameter` 任务的两个种子最终都没有选出真实共享参数结构，保留的是近似公式。该任务的自动发现能力仍有缺口，不能把固定结构拟合通过包装成自动结构恢复成功。

最终 14 个联合模型全部满足预先冻结的验证退化约束。该约束参照是训练初始化公式，保护的是这一起点，不保证胜过完整独立 DimenSR。全体 70 系统保存前后训练/验证预测哈希与域审计一致，独立指标重算最大差为 8.67e-19；全部最终声明域为 enclosed。原始表达式非法及 unresolved 拒绝有独立测试和候选日志。

## 本轮范围

这是合成开发验证。未开展新的真实数据盲评，也未将量纲、区间、Rademacher、尺寸多样性开关扩展成完整性能矩阵；这些开关已有可运行测试。预算未耗尽便按预注册矩阵结束，没有为取得优势继续调优。下一轮若要研究搜索收益，应另建新实验，保留本轮结论与冻结文件。
