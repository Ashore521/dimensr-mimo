# 精确量纲计算提速与机制覆盖

1.2.1在同一Concrete Slump预算下恢复六个联合系统的完整运行机制，主核验和原物理交付复算均为6/6。上一轮可选phased配置为2/6。本轮六个系统都有有效神经候选、策略更新、GP新评价、四代有效NSGA-II和局部Rademacher；数据、划分、量纲、52秒fit、60秒系统及1200评价上限不变。

精度并未因此通过：完整精度/结构验收仍为0/6，18个配对输出只有14个受保护，平均历史测试NRMSE从0.64876升至0.69622，约上升7.3%。这支持计算效率和机制覆盖修正，不能支持精度优势或phased默认推广。默认仍为global/legacy/weighted；六个模型的物理验收均为`not_met`。

## 改动与等价边界

训练侧profile定位到重复的Fraction二元运算和追踪特征构建。第一候选使用LRU缓存，ABBA总耗时只改善约2.3%，神经生成反而变慢；该候选保留于实验目录但未采用。

采用的实现用所有现有量纲Fraction分母的最小公倍数建立精确整数格点，按原次序枚举乘除法生产规则；加减法直接枚举同量纲对。没有浮点量纲近似，也没有改变合法生产范围。追踪特征在语法实例内缓存，返回副本防止调用者污染缓存。

在同一训练侧工作负载（一次三输出语法构建、一个输出的结构初始化、八个神经提案）中，ABBA平均耗时从15.83秒降至12.08秒，约减少23.7%；种子、初始化计数和神经提案哈希完全一致。独立回归同时核验Fraction量纲生产顺序、完成cost、掩码、trace及缓存修改隔离。无墙钟截断的小型完整搜索，其搜索指纹、候选池、参数、预测及变异计数完全一致。

这种等价性不意味着有墙钟限制的搜索结果相同：提速使同一窗口容纳更多提案，后续随机数使用和候选池随之改变。本轮平均测试误差上升和四个输出退化均保留，不能用语义等价掩盖性能差异。
