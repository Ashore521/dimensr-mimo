# DimenSR-MIMO 1.8.0

1.8.0 加入可选的多输出结构搜索。它按训练响应筛选量纲合法的基函数方向，分别保留每个输出的不同候选结构，并在组装计算图时复用完全相同的节点。常数继续由原生拟合器估计。新搜索需要等量纲、输入闭域和结构容量检查通过，才能接受模型。

通过 `SearchConfig.accuracy_portfolio(max_evaluations=120, portfolio_settings={'structural_discovery': True})` 启用。可按任务指定算子、结构上限及常数单位。在复现实验的最差输出验证误差时，按各完整候选的最大验证 NRMSE、平均验证 NRMSE、复杂度和索引逐级排序，将入选索引传给 `model.predict(X, selection=index)` 和 `model.formulas_for(selection=index)`。

## 配对验证

每个版本在每个单元内均预算 120 次原生拟合或精修。两个版本使用相同任务数据和成对的种子。新任务由独立设计者封存，搜索完成并冻结全部模型后才打开测试数据和真值。

| 指标 | 18 道开发题，边界修复版 → 结构搜索版 | 4 道新盲题，边界修复版 → 结构搜索版 |
|---|---:|---:|
| 无噪完整系统恢复 | 7/42 → 15/42 | 0/9 → 6/9 |
| 含噪系统达标 | 2/12 → 6/12 | 0/3 → 0/3 |
| 符号等价输出 | 20/123 → 40/123 | 0/30 → 12/30 |

两道新无噪题的所有种子均完整恢复。第三道无噪题的最差输出误差中位数下降 31.16%，含噪题中位数持平。以上任务均为 2–3 输入的合成任务，高维工程精度需独立测量。
