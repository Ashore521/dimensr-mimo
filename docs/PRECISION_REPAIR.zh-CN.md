# 训练触发的精度补充（1.7.0 开发选项）

`SearchConfig(precision_repair=True, initialization='compound', sharing_strategy='closure', final_selection='precision', acceptance=...)` 在原完整神经、GP、NSGA-II 和 polish 搜索后检查训练精度。默认 `precision_repair=False`；生产默认和既有接受阈值不变。

仅在原基础池没有任何候选满足所有输出的 `acceptance.nrmse` 时，才使用训练数据生成隐式有理初值。触发条件不读取结构指标、验证标签、测试标签或任务名。每输出至多 `min(12, population_size//n_outputs)` 个初值，按相同索引组合；该索引没有初值的输出从固定训练最优基础父系统复制。组合必须含至少一个实际获胜的隐式初值，才有资格进入原完整系统评价器。

最多新增 12 次缓存外系统评价，已有成功或失败缓存均跳过，不重拟合基础状态。固定父系统按平均训练误差、复杂度、图摘要排序选出；每输出训练误差不超过父误差 `1.1 倍 + 1e-8` 才保留。之后执行原 24+24 次匹配闭包。所有新增评价共用原全局评价数和时间预算；新增初值生成在特征、乘积、beam 和线性子问题间检查截止时间。单次 NumPy/BLAS 运算不能被该合作式检查抢占；正式实验继续使用 52 秒合作式 fit 截止和 60 秒外部进程上限。

`diagnostics.sharing_closure` 的基础数量、摘要及搜索指纹始终记录补充前的基础池，最终 precision 选择仍以该基础池为参照。`precision_repair` 子记录保存触发、固定父、初值来源、独立新评价数及保留/拒绝事件；外层闭包计数仍仅表示匹配闭包。完整训练池顺序为基础、已保护补充、已保护匹配；验证过滤不会重新启动搜索。旧模型先按其原配置验证保存的来源摘要，再迁移新增默认值。

2026-10-30，`experiments/precision_repair_20261028`完成34/34技术核验及34/34配对输出保护，17/17基础搜索一致，15个未触发单元的候选池和选择完全一致。完整接受10/17→11/17；指定有理式达到机器精度和图规模15/4参数，指定阻尼案例原图规模20/4参数保留。该批事前采用门槛及独立后审通过，仍有6个系统未完整接受。

随后固定源码的`experiments/new_task_validation_20261030`覆盖4个此前未用于本项目诊断的合成双输出公式族、两种噪声及两个种子。32/32系统技术通过，32/32配对输出保护，16/16基础身份一致；完整接受5/16→7/16，未达到事前16/16要求，整体验收失败。新增接受仅来自双线性饱和族两个无噪声单元；对数族和代数范数族没有接受增益，logistic族零触发。独立后审复算32所选模型和530扩展事件，支持上述结论；没有独立重算全部5330候选或initializer。
