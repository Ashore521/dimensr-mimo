# 共享结构发现：补齐带参数频率的通用种子

第四轮完成40/40个系统，全部通过独立核验，耗时14.82分钟。两组使用同一个已冻结的guarded选择器；唯一搜索干预是在原类型化种子后追加合法的 `sin(c*x)`、`cos(c*x)` 及其幅值形式。没有增加常数拟合预算或更改生产源码。

|指标|原搜索+guarded|补齐种子+guarded|
|---|---:|---:|
|平均测试NRMSE|4.92037e-5|4.28351e-16|
|平均复杂度|24.2732|18.8327|
|共享频率任务最终恢复同一参数身份|0/5|5/5|
|实际搜索总墙钟|391.19秒|390.34秒|

20个配对为5改善、15持平、0退化（绝对容差1e-8）；40/40个输出满足相对控制组的预定测试保护阈值。平均复杂度降低22.4%。精度改善集中在shared_parameter任务；其余三个任务本来已接近浮点精度，不能把数值尾差解释为进一步精度收益。

诊断显示，旧种子词汇包含square/sqrt/log/exp的参数化结构，却缺少对应sin/cos结构。旧完整轨迹中的82个有效新绑定有48个进入最终池，说明绑定确实执行；但缺少适当上游根结构。本轮补齐通用词汇后，5个新种子的最终系统都显式连接了同一个频率参数。相等的两个独立常数不计为共享。

新种子只依赖输入、算子、量纲和结构上限，不编码目标频率1.7、目标标签或输出配对。新增初始化评价仍占用原有预算，并会改变后续随机搜索路径。该结果支持这一已知任务上的结构覆盖改进；不能推断任意共享表达式均可恢复，也不是未见任务盲评。

40/40系统均有神经参数更新、有效神经候选、GP新评价及多代NSGA-II证据。控制组的跟踪包装在人工数据上与不跟踪运行产生相同候选池和搜索指纹。独立验证重算候选选择、全部已记录成功拟合的训练误差、模型预测、指标、数值域与轨迹计数，最大指标差1.42e-14。所有域enclosed仍只表示有限浮点数值筛查。
