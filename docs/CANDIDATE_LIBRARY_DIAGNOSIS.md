# 候选库与选择机制诊断

本轮完成了对 contextual_transfer_v1 全部 45 个开发单元、六种方法的回溯诊断。
主要发现是：当前保留的候选中存在更好的外层拟合，但单次内层验证难以将它们选出；
继续增加内部子树迁移尚无充分依据。下一轮优先研究候选排序的稳定性，并保留现有算法默认值。

这里的“事后最优”使用了已经看过的外层标签，只用于定位问题。
它不是可部署的选择规则、可达到的泛化上界，也不是新的盲测成绩。
本轮没有重新训练、拟合系数、改变算法或打开新的外部测试集。

## 诊断范围与比较口径

沿用原来的三个嵌套划分、每个划分五个搜索种子，共 45 个单元。
混凝土坍落度为 7 输入、3 输出，Parkinson 为 16 输入、2 输出，空气质量为 8 输入、3 输出。
原有分组、时间顺序、拟合样本上限和标准化均保持不变。

重新计算了 27,420 个固定候选的内层和外层误差，精确枚举了 12,948,442 个系统组合。
标量候选可组合成系统；joint25 的完整系统保持不可拆分。
系统复杂度 K 按共享 DAG 节点并集、非零系数和截距计数，不是各输出复杂度之和。
公式与系数的序列化表示完全相同时保留原始索引别名；本次完整候选没有精确重复项。
逐输出排序另外去除零权重基函数并去重，避免联合模型的冗余投影影响排序统计。

比较三个上限：本方法原已选模型的 K（own）、同单元 independent25 已选模型的 K（common），
以及不设上限的辅助检查。主要诊断采用前两种。系统汇总对三个数据集等权，NRMSE 越低越好。

## 同一复杂度下确有候选余量，但不是已经实现的提升

下表的事后最优值受各方法自己的原已选系统 K 约束。因此适合看方法内部的剩余空间，
方法间候选质量比较应使用下一节的共同上限。

| 方法 | 原已选模型 NRMSE | 库内事后最优 NRMSE | 事后差距占原误差 | 差距至少 1% 的单元 |
|---|---:|---:|---:|---:|
| independent20 | 0.889092 | 0.840939 | 5.42% | 37/45 |
| independent25 | 0.887598 | 0.839387 | 5.43% | 37/45 |
| semantic25 | 0.892289 | 0.832782 | 6.67% | 39/45 |
| whole25 | 0.886255 | 0.831310 | 6.20% | 39/45 |
| context25 | 0.886178 | 0.833105 | 5.99% | 38/45 |
| joint25 | 0.918713 | 0.887837 | 3.36% | 25/45 |

context25 的三个数据集分别为：

| 数据集 | 原已选系统 | own 上限事后最优 | 事后差距 |
|---|---:|---:|---:|
| 混凝土坍落度 | 0.656122 | 0.607131 | 7.47% |
| Parkinson | 1.009700 | 0.988136 | 2.14% |
| 空气质量 | 0.992712 | 0.904048 | 8.93% |

不能把 5.99% 视为优化目标的已验证收益：候选越多，利用外层标签选择时碰巧改善的机会也越多。
这些数值只描述已保存候选，不能证明整个搜索空间已充分覆盖。

## 问题集中在候选排序，单改复杂度偏好作用很小

原 compact 规则先要求每个输出的内层归一化 MSE 不超过该输出最小值的 1.01 倍，
再寻找最小共享 DAG 系统。在原已选 K 上限内，context25 的平均差距可分解为：

- 1% 筛选范围内尚未利用的事后差距：0.000004832。
- 被该筛选范围排除的候选带来的事后差距：0.053067787。
- 总差距：0.053072619，约 99.99% 位于原筛选范围之外。

这项分解不能证明“把 1% 调大就会变好”。原 compact 已选择筛选范围内的最小 K，
所以 own 上限下的筛选内组合本来就受到很强约束；它主要排查了这个固定上限下的选择余量。
被排除的候选有较差的内层验证排名，新的规则仍须在未知结果上证明能可靠选中它们。

仅在相同候选和 own 上限内改为“平均内层 NRMSE 最低”，context25 的外层平均值从
0.886178 变成 0.887628，增加 0.164%；45 个单元中 1 个改善、43 个基本相同、1 个变差。
因此，当前证据不支持只降低复杂度惩罚或直接追求更低的单次验证误差。

共同 K 上限的全部候选集合都非空，但同时满足 1% 筛选的集合可能为空：
independent20、independent25、semantic25、whole25、context25 分别有 5、0、15、19、15 个空集合。
表格明确保留这些缺失，不放宽上限补数；joint25 不适用这项逐输出筛选分解。

## 内部子树迁移尚未改善共同上限下的候选质量

| 方法 | 共同 independent25 K 上限：库内事后最优 NRMSE |
|---|---:|
| independent20 | 0.840662 |
| independent25 | 0.839387 |
| semantic25 | 0.832308 |
| whole25 | 0.834092 |
| context25 | 0.834654 |
| joint25 | 0.889459 |

context25 相比 independent25 的事后最优值低 0.56%，逐单元为 26 胜、15 平、4 负；
相比 whole25 高 0.067%，为 13 胜、15 平、17 负。
与 whole25 的差距主要出现在空气质量，平均 NRMSE 高 0.005425；
混凝土和 Parkinson 的差值分别为 -0.003052 和 -0.000687。
这与上一轮未通过内部迁移归因门槛的结果一致，尚不支持优先增加内部替换频率或搜索深度。

不设 K 上限时 context25 的事后值为 0.821047，whole25 为 0.821879，semantic25 为 0.821097。
这一敏感性检查说明结论与复杂度约束有关，不能将共同上限下的结果推广成内部迁移普遍无效。
所有这些比较仍受候选数量和外层标签事后选择的影响。

## 哪些输出最需要关注

以下仅列 context25；完整表保留六种方法、八个输出。
逐输出事后值采用各自已选活动输出头的 K 上限，不可相加冒充系统结果。
排序相关性为候选内层与外层 NRMSE 的 Spearman 相关系数，再对 15 个单元求均值。

| 输出 | 原 NRMSE | 逐输出事后 NRMSE | 平均排序相关性 |
|---|---:|---:|---:|
| SLUMP | 0.909414 | 0.862331 | 0.523 |
| FLOW | 0.812604 | 0.764736 | 0.577 |
| 抗压强度 | 0.246347 | 0.233728 | 0.721 |
| motor_UPDRS | 1.026157 | 1.008020 | 0.380 |
| total_UPDRS | 0.993244 | 0.971600 | 0.530 |
| CO | 0.393403 | 0.377863 | 0.702 |
| NOx | 1.752213 | 1.627066 | 0.295 |
| NO2 | 0.832521 | 0.721054 | 0.216 |

空气质量的 NOx、NO2 排序一致性较弱，且事后差距较大，应优先检验时间块之间的排序稳定性。
Parkinson 的 motor_UPDRS 在这一候选库和输出头复杂度上限内，即使按外层标签选取，
平均 R² 仍为 -0.00555；total_UPDRS 为 0.03436。因此它还有筛选之外的限制，
需要区分分组外推、输入信息和候选表达式能力，不能承诺更换选择器就能解决。

## 建议下一步：验证稳定性驱动的选择器

下一项建议为独立的 `robust_selection_v1` 实验，本轮未实现或运行。

1. 固定当前独立搜索和 whole-basis 转移机制作为对照，先研究选择环节。
   在数据允许时采用重复分组验证；空气质量采用连续时间块验证，保持时序和间隔规则。
   内部子树迁移保留为后续可选消融，不继续提高它的预算。
2. 比较现有 1% compact、仅按平均验证误差选择，以及考虑验证波动的保守选择规则。
   例如允许统计不确定性范围内的候选参与共享 DAG 压缩，同时设置每个输出的退化约束。
   容差和重采样次数必须预先限定，不能按本轮外层最优索引反推。
3. 严格分离候选发现与评分。若内层验证折改变，候选生成和系数拟合也必须遵守相应训练范围；
   不能对在评分样本上发现过的结构重新打分，就称作交叉拟合验证。
   同时核算搜索、重拟合和选择的总 CPU 成本，给对照相同总预算。
4. 首先在这三个已知开发任务做消融，报告逐输出误差、K、失败率和稳定性；
   达到预先冻结的门槛后，再使用未用于调参的新外部任务确认泛化。
   Parkinson 单列诊断，避免用它或空气质量的弱输出被系统均值掩盖。

本轮排序诊断没有给出新选择器的预期收益，也不改变之前的失败门槛结论。
同一数据划分上的五个种子并非五个独立数据实验，不报告 IID 显著性结论。

## 核验和复现

195 项测试通过，新增 10 项覆盖共享 DAG 上限、常数值区分、精确组合、去重、筛选影响、
联合模型不可拆分、非有限外层预测保留、常数排名、输入不可变及冻结与检查点校验。
冻结的 440 个输入和代码文件全部保持原字节。
27,420 个存档验证损失的最大重算差异为 3.11e-15；
270 个原模型的 2,880 个内层/外层 NRMSE 与 R² 分量最大差异为 3.56e-15。
所有已保存候选在本次外层有限样本上的预测均有限，但这不是新的连续区域合法性证书。

额外用原实验的组合与指标代码，重建了 2,241 条选择记录对应的 826 个不同系统，
核对 4,482 个平均 NRMSE 值，最大差异为 2.00e-15。
七个汇总文件在另一目录重建后逐字节相同；从 CSV 独立重算的等数据集权重均值和差距分解也一致。
诊断后重建审计单独固定在 `AUDIT_FREEZE.json`，不改动最初的 `FREEZE.json`。

已有数据和环境的本地仓库中，可以执行：

```bash
python -m pytest tests/test_candidate_diagnosis.py -q
python experiments/candidate_diagnosis_v1/candidate_diagnosis.py batch
python experiments/candidate_diagnosis_v1/analyze.py --out outputs/candidate-diagnosis-new-recheck
```

`batch` 会核验并复用已完成检查点，不覆盖结果。分析输出目录必须尚不存在。
新机器需自行取得并校验原开发数据；原始数值数据、用户论文 PDF 和 Word 不在公开提交中。
