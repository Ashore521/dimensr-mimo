# 含噪声与新公式族开发验证

三类预声明公式族（阻尼三角、有理二次分母、高阶多项式）、两个噪声级、两个种子和三方法，共36系统，36/36独立核验通过，冻结至核验651.39秒。所有搜索均完成神经生成/更新、GP、多代NSGA-II、局部Rademacher、量纲及域筛查。两种联合方法使用同一precision选择规则，差异仅为初始化。

|方法|完成/核验|完整训练验证及测试验收|平均干净测试NRMSE|平均图size|
|---|---:|---:|---:|---:|
|legacy联合初始化|12/12|3/12|0.04025653|20.92|
|dimensional联合初始化|12/12|3/12|0.02161196|21.33|
|逐输出独立DimenSR|12/12|0/12|0.03424089|22.92|

新初始化平均干净测试误差降低46.3%，但未增加完整验收数；相对旧初始化，23/24输出满足预冻结测试保护界，推荐门槛未通过，默认配置不变。唯一超过保护界的是含噪多项式、种子701的第一个输出，NRMSE绝对增加约4.32e-5；该系统仍通过绝对精度及结构阈值。小幅退化也保留在保护分母中。

新旧两种联合方法在无噪声层各2/6通过，在1%噪声层各1/6通过。新初始化恢复两种子无噪声多项式，干净测试误差约1e-16；一个含噪多项式同时通过误差与结构。另一个含噪多项式虽然干净误差很小，但冻结池中没有同时满足误差、结构及保护条件的模型，正确保留not_met。

阻尼三角和有理分母两类仍失败。无噪声代表单元的候选池分别有159和157个模型，满足绝对误差的候选均为0；它们的真实图已在搜索前确认量纲合法、可由语法表示且在结构限额内。因此结果支持进一步诊断复合项发现能力，不能仅靠更换最终选择器解决。

这36个系统均使用相同总评价和墙钟上限，不因失败补跑、调参或放宽阈值。所有模型冻结后才生成测试标签；测试使用观察噪声与干净真值两套指标，完整逐输出结果见[评分](../experiments/noise_families_20261026/SCORES.json)和[独立核验](../experiments/noise_families_20261026/VERIFICATION.json)。两种子不是独立物理数据集，全部任务由开发者预声明，不能称盲评或真实数据验证。
