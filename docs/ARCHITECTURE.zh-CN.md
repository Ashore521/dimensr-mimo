# 静态多输出 DimenSR 重建规格

输入 X(n,p)、Y(n,q)，一个搜索个体是含 q 个根的有向无环表达式图。节点有稳定引用，常数有显式参数编号。同值不自动绑定。每个根可表达完整非线性公式。跨根引用、绑定/解绑参数、共享节点共同变异及私有分支变异均进入搜索；无共享的森林同样合法。

## 源码继承

原版 DimenSR 0.4.0，提交 `7fbcefadd105fe6266c8149cc05420de8ca74a76`，来源及逐文件 SHA256 见 UPSTREAM.json。`_single` 保持源文件字节不变，既提供数值语义/量纲/区间基础，也用于完整逐输出独立对照。

| 原版模块 | 新版职责 |
|---|---|
| expression / units / intervals / domains | 多根 DAG 原始计算；展开仅用于原始树区间审计，保留全部除法、log、sqrt；继承量纲与无标签域探针 |
| grammar | 有类型的完整公式生成，增加先前输出子图引用终结符与输出上下文 |
| policy | GRU token/量纲产生式概率、系统级风险寻优策略梯度、优秀系统模仿 |
| genetics | 同量纲交叉/变异，增加共享引用、共同编辑、解除共享和参数绑定/解绑 |
| fitting / evaluation | 联合常数拟合、训练评价、严格原始图合法性；真实共享参数只拟合一次 |
| complexity | 共享 DAG 复杂度、全部输出对联合参数的 Jacobian、局部线性化 Rademacher |
| pareto | 两目标非支配排序、拥挤距离、尺寸密度；逐输出约束优先支配 |
| regressor | 神经/GP 交替探索后 NSGA-II 多代父子代合并，最后使用验证集选模型 |

## 固定统计定义

训练输出尺度 s_j=std(Y_j)，若近零则 max(RMS(Y_j),1)。联合拟合损失为 mean_ij[((F_ij-Y_ij)/s_j)^2]。搜索第一目标为各输出 NRMSE 的算术平均；平方损失只用于连续常数拟合，不冒称与平均 NRMSE 完全相同。

第二目标 C=w0*(唯一非参数节点数+唯一参数数)+w1*不同算子种类数+w2*R_scaled。显式共享节点计一次，绑定参数计一次，独立同值常数各计一次。尺寸多样性使用同一共享结构尺寸。默认权重 (1,0.5,2)。

逐输出参照在训练初始化结束时冻结：从合法初始系统中分别取每输出训练 NRMSE 最小值。阈值为 ref_j*(1+0.10)+0.02；误差超额之和为约束违反量。可行者优先，不可行者按违反量排序，同违反量再做两目标 NSGA-II，不增加第三目标。该参照是初始化保护基线，不代表已达到独立完整 DimenSR 的精度。

所有结构、参数、参照、尺度只用训练数据和声明的无标签域。搜索结束冻结候选后，才用验证标签计算同一参照模型的验证误差及候选逐输出约束，最终在可行候选中按验证平均 NRMSE 优先、固定复杂度惩罚选择。无验证可行候选则明确报告约束不可满足，按预先定义的最小违反量回退；不隐瞒失败、不改阈值。测试标签不进入 fit。

局部 Rademacher：向量化归一化系统输出，N=n*q，J∈R^(N×P)，P 为唯一自由参数数。训练固定的独立样本-输出符号 σ∈{−1,+1}^N，Q 为 J 非零列空间正交基。函数族 {Qa:||a||≤ρ√N}，估计 R=ρ/√N mean||Qᵀσ||，R_scaled=R√N/ρ。共享参数对所有关联输出只有一列。它仅衡量已拟合结构的局部线性化函数族，不是整个非线性结构搜索类的泛化保证。

## 实施批次与验收

1. DAG、生成和联合拟合：共享/私有/部分共享、共享非线性参数、不同尺度和量纲；拒绝原始表达式 invalid/unresolved。
2. 系统神经/GP/NSGA-II：日志核对参数变化范数、有效神经候选、GP 新后代、多代新评价、共享算子实际影响，开关消融。
3. API/JSON/CLI/测试与安装：保存加载预测及域审计一致，不用 pickle；CI 构建安装。
4. 首轮性能：资源预检、短校准、冻结设计后，最多两小时总墙钟。完整逐输出独立 DimenSR 按整个系统分配同预算，保留所有失败。合成问题属于开发验证，不能宣称盲测或普遍优势。
5. 发布全新历史并清理旧远程 refs。仅发布代码、合成生成器、日志和聚合结果，不发布原始数据数组或私有文献。

量纲、区间、局部 Rademacher、尺寸多样性、神经、GP、共享机制均有独立消融开关。默认严格区间检查；关闭区间只能称有限点检查消融。有限数值区间筛查不是全域形式化证明。
