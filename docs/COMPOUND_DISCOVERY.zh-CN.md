# 1.4.0 可选复合项初始化

`SearchConfig(initialization='compound')` 在完整联合MIMO搜索中启用有界复合项初始化，保留原默认 `legacy` 和既有 `dimensional` 模式。完整词汇语法此前已有exp；此次补齐的是结构初始化中的参数化指数、独立移位分母、按训练相关度筛选的有限乘积，以及不强制附加截距的紧凑单项。

特征总数仍≤512，结构特征节点上限显式从9改为11，整输出仍遵守配置的节点和深度上限。初始化评价份额、神经/GP/NSGA-II和常数拟合预算没有扩大。只使用训练观测排序，不识别任务名称或注入真值公式/系数。生成、拟合及最终验收仍执行量纲与严格数值语义。

[38系统开发回归](../experiments/compound_search_20261027/REPORT.zh-CN.md)中，候选完整接受7/17，对照5/17，去乘积消融0/4；34/38系统完整技术核验通过，另4个GP中间量纲异常保留。逐输出保护28/34，推荐未通过。候选曾在阻尼任务上达到机器精度，但图规模27超过24，仍明确not_met，未消去近零项来改判。
