# 相对于原选择结果的逐输出保护

本轮通过全部预定推荐门槛。80/80 个最终系统及 40/40 次实际搜索核验通过，40/40 个测试输出满足相对于原选择器的保护阈值。正式阶段耗时 1137.69 秒（18.96 分钟），低于新设的 60 分钟上限。完整结果见 [实验报告](../experiments/guarded_selection_20261026/REPORT.zh-CN.md)、[核验记录](../experiments/guarded_selection_20261026/VERIFICATION.json)和[全部配对](../experiments/guarded_selection_20261026/SUMMARY.json)。

|方法|平均测试 NRMSE|平均复杂度|
|---|---:|---:|
|原联合选择器|1.96205e-4|23.6859|
|取消复杂度惩罚|5.81419e-5|31.0182|
|逐输出保护＋同精度简化|5.81419e-5|24.6498|
|完整独立 DimenSR|2.42366e-4|19.3720|

带保护选择器相对原联合方法平均误差降低 70.4%，复杂度增加 4.1%；20 个配对为 6 个改善、14 个持平，没有系统均值或逐输出误差的实质退化。相对取消复杂度惩罚，20 个配对的测试精度均在预设 1e-8 容差内持平，平均复杂度降低 20.5%。

本轮新种子上，取消复杂度惩罚也没有触发测试退化超限。因此这轮明确支持同精度简化的复杂度收益，不能据此单独量化逐输出过滤降低测试退化概率的效果。验证过滤的正确执行已独立核验；测试保护的成功属于本轮观测结果。

在这四类已知任务范围内推荐采用带保护选择规则。生产默认配置继续保持原样，待后续独立搜索机制比较及未见任务验证。相对独立 DimenSR，本轮为 3 个改善、15 个持平、2 个较差，仍不能将总体均值优势外推到所有种子、输出或真实数据。

第二轮取消最终复杂度惩罚后，系统平均误差降低，但部分输出退化。因此本轮将最终选择分成三个明确步骤：

1. 在冻结候选池中，按原复杂度权重 0.01 的规则确定参照模型，保持其最小约束违反量层级。
2. 候选每个输出的验证 NRMSE 必须不超过原参照输出误差×1.10+1e-8。
3. 在通过保护的候选中找到最低平均验证误差；其 1%+1e-8 范围内优先选择复杂度更低的模型。

这项规则只保护验证误差，不保证测试误差不退化。相对/绝对容差均在正式训练前固定，测试结果不用于改变规则。

原联合、无复杂度惩罚、带保护选择器共享一次联合搜索产生的冻结候选池，另设完整逐输出独立 DimenSR 对照。四类已知合成任务、五个新种子共 80 个最终系统，实际是 40 次搜索和 40 次派生选择。统计同时记录实际新增计算与方法单独使用时需承担的共享搜索成本。

正式协议、源码和环境见 [实验协议](../experiments/guarded_selection_20261026/PROTOCOL.md)与 [FREEZE.json](../experiments/guarded_selection_20261026/FREEZE.json)。独立核验会重算候选的验证误差、过滤规则、最终选择、预测和域筛查。所有最终模型及选择记录冻结后才生成测试数据。

派生模型 JSON 保留原训练配置及原候选评分，实际选择规则写在 `post_selection` 中。已有模型加载器可用于这些 JSON 的预测；审计选择过程时应读取 `post_selection`，不能仅凭原训练配置判断所用选择器。

本轮只检验选择规则。共享结构发现、常数拟合预算和生产默认配置保持不变；共享搜索改动将另立实验。该结果属于已知任务的新划分开发验证，不是未见公开任务或真实数据盲评。
