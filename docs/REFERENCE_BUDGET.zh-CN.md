# 共享引用的展开结构预算

1.3.0增加可选`reference_budget='expanded'`，生成阶段按共享引用的实际展开节点数和深度计算预算。六个同预算Slump系统均完成完整机制及物理复算，110/110个实际神经提案在送入数值评价前符合展开结构上限，违规数为0。相对1.2.1的token模式，18/18输出满足预登记保护界，平均历史测试NRMSE由0.69622降至0.67975，约下降2.4%。

完整精度/结构验收仍为0/6，所有模型保留`not_met`。保护界为旧误差×1.1+1e-8，允许一定增长；它不等于所有输出都改善。例如dimensional/801第一输出从0.84013升至0.92063，约增长9.6%，仍在该保护界内。默认继续使用token/global/legacy/weighted；单一历史数据集不足以支持普遍推荐或工程应用。

## 修正范围

原语法把r引用当作一个普通终结符，展开图却可能超过max_nodes/max_depth，随后被评估器拒绝。训练侧八提案诊断中仅一项通过展开图检查，提示生成预算与最终预算不一致。

新模式向语法传入每个引用的展开大小与深度，用于最小完成cost、选项mask、递归兄弟节点的剩余预算及策略trace回放。SystemGrammar缓存键同时包含引用单位和结构，避免同量纲不同大小的引用混用规则。DAG与参数身份仍显式共享；没有复制共享节点或放宽最终上限。没有引用时，新旧模式保留相同提案。

该模式改变共享搜索分布，不能沿用1.2.1纯提速的完整搜索等价结论。token默认仍通过与冻结旧语法的无墙钟完整搜索一致性测试。数值域、量纲、原始除法/log/sqrt与参数拟合仍独立检查，结构合法并不等于数值合法或精度通过。
