# 绝对精度约束下的结构优先交付

从第七轮48个冻结候选池派生48个模型，没有新增搜索或常数拟合；先按训练/验证约束选模并封存全部模型，再统一复算已知测试集。48/48核验通过，用时36.70秒，96/96个测试输出满足相对原guarded结果的保护界。

|来源方法|可行交付/测试达标|平均共享图size|原guarded平均size|
|---|---:|---:|---:|
|balanced|6/12|14.6667|14.6667|
|aligned|8/12|13.4167|13.4167|
|normalized|12/12|12.5000|12.5000|
|combined|12/12|12.0833|12.0833|

新选择规则仅在同时满足绝对精度、结构上限、训练及验证逐输出退化约束、guarded验证保护界的集合中，依次最小化共享图size、独立参数、展开节点和深度。没有可行系统时，保留guarded预测并返回明确的not_met状态；该验收记录在模型重载、再保存后保留。

本轮没有产生额外的平均结构压缩收益，不能称新选择器提升了精度或压缩能力。它补齐了交付契约：是否满足预定逐输出精度与结构要求有明确、可复算的状态。生产默认未变；研究候选仍优先采用第七轮改动较少的normalized方案，真实应用与噪声验证尚未完成。
