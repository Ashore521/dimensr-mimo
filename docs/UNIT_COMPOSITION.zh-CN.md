# 跨输出类别对齐与量纲组合

48个完整联合系统全部通过独立核验，用时1117.24秒（18.62分钟）。2×2比较沿用第六轮任务、种子、精度和结构门槛，属于已知任务开发回归。

|方法|精度与结构同时达标|平均测试NRMSE|相对对照输出保护|
|---|---:|---:|---:|
|平衡分配对照|6/12|0.01461632|—|
|仅跨输出类别对齐|8/12|0.00896114|22/24|
|仅量纲结构组合|12/12|8.49e-15|24/24|
|两者组合|12/12|8.49e-15|24/24|

12个对照候选池与第六轮对应池完全一致。类别对齐单独修复了不同输出单位的三角任务，但有两个配对退化；不能只引用其达标数量增长。量纲组合与组合方法各有6个配对改善、6个持平，无配对退化，所有输出保护通过。

量纲组合的改变限定在结构种子：当声明目录中存在逆量纲常数时，先构造合法的系数×原始项，再生成sin/cos/log/sqrt等组合。所有常数仍在完整系统上拟合；原神经策略、GP、两目标NSGA-II、局部Rademacher、原始数值语义和逐输出约束保留。总评价上限、结构特征容量、保留名额和常数拟合预算不增加，实际耗时单独记录。

两个有效方法在本开发层均达标，后续优先使用改动更少的“平衡分配+量纲结构组合”作为研究候选。生产默认保持原样；本结果不证明噪声鲁棒性、新任务泛化或实际工程精度。结构优先交付选择将在同一冻结池上另立比较，不并入本轮效果归因。
